스킬의 워크플로우(컨벤션 로드 → 요구사항 분석 → Phase 분할 → 계획 문서 작성 → **사용자 승인** → Phase별 실행 → Quality Gate)를 반드시 그대로 따른다. 사용자 승인 전까지 절대 코드 수정을 시작하지 않는다.
